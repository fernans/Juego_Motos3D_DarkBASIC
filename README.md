# Juego_Motos3D_DarkBASIC — DarkBASIC prototype of the motorcycle game

Standalone demo of the **3D motorcycle variant** of the "Juego Motos" proposal, compiled with **DarkBASIC Professional** (`DemoMotos.exe` — a virtual-packed DBPro executable that embeds its own `media/` content, so it runs on its own).

It was the fastest way to prototype the 3D approach (a bike riding over a terrain with a low-poly motorcycle model) before the production engines were attempted in other variants (`Juego_Motos3D_SDL_plib`, `Juego_Motos2D_Flash`, `Juego_MotosVideo_Bancaja`).

- `DemoMotos.exe` — the runnable prototype (6.4 MB).
- `Motos3D_intentoDarkBasic.rar` — the packed project attempt (attached as a **GitHub Release asset**).

Produced by **Mediterrania Multimedia**.

> **This project is shared ONLY for educational purposes. Its use, direct or derived, for professional or economic purposes is not permitted.**

## Requirements / How to run

- **OS:** Windows XP/Vista-era system.
- **Run:** just execute `DemoMotos.exe` — everything is embedded (DBPro virtual pack).
- **Source:** unpack `Motos3D_intentoDarkBasic.rar` (Release asset) and open the project in DarkBASIC Professional.
